# 🚀 Nova – AI Chatbot Assistant

Nova is a modern full-stack AI chatbot built using **HTML, CSS, JavaScript, Node.js, Express.js, and the Gemini API**.
It features a sleek UI, real-time streaming responses, markdown rendering, speech recognition, syntax highlighting, and secure API architecture.

# 📦 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/Gemini-Chatbot.git
cd Gemini-Chatbot
```

---

# ⚙️ Backend Setup

## Install Dependencies

```bash
npm install
```

## Create `.env` File

```env
GEMINI_API_KEY=your_api_key
```

---

# ▶️ Run Locally

```bash
node server.js
```

Open:

```bash
http://localhost:5000
```

---

# 🔐 Security Improvements

Initially, the Gemini API key was exposed in the frontend.
To improve security:

* API key was moved to backend environment variables
* Backend API routes were created using Express.js
* CORS protection was configured
* `.env` file was excluded using `.gitignore`
